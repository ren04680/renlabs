Use the same labels as the Apple Global School knowledge base:
`VERIFIED` / `HISTORICAL` / `CONFLICT` / `UNKNOWN`.

---

## 1. Identity & location
- [ ] Full official name and the abbreviation used publicly
- [ ] Founding year, founder, parent trust or group
- [ ] Exact campus address, area, city, PIN code
- [ ] Campus name (Rajbaug?) and size/acreage if published
- [ ] How to describe the location to someone unfamiliar with Pune (nearest landmark,
      distance from Pune station / airport) — only if officially published
- [ ] Official phone numbers, email addresses, website
- [ ] Admissions-specific contact, if different from the general one
- [ ] Office hours

## 2. About the university
- [ ] Vision, mission, tagline as officially worded
- [ ] Number of constituent schools/institutes **and their exact names**
- [ ] Student and faculty numbers — and whether these are the university's own claim
- [ ] Accreditations and recognitions, worded exactly: UGC status, NAAC grade (and the
      year awarded), NIRF rank (and category + year), any others
- [ ] Named leadership: Chancellor, Vice Chancellor, Registrar, Deans

## 3. "Best things about the university"
This is the weakest kind of claim to get wrong, so it needs the most care.
- [ ] Which strengths the university itself publishes (labs, studios, industry tie-ups,
      incubator, international partnerships, notable alumni)
- [ ] Placement figures — **with the cohort year, the reporting methodology, and whether
      the figure is median, average or highest package.** A bare "100% placement" or a
      headline package number cannot be used
- [ ] Rankings — exact rank, exact category, exact year, exact issuing body
- [ ] Any awards or recognitions, with the awarding body and year

## 4. Course details
For **every** programme the agent should discuss:
- [ ] Exact programme name as published (e.g. "B.Tech Computer Science and Engineering")
- [ ] Duration
- [ ] Which school/institute runs it
- [ ] Eligibility criteria
- [ ] Entrance exams accepted (JEE Main / MHT CET / PERA CET / MITID DAT / CAT / MAT /
      university test) and which applies to which programme
- [ ] Intake/seats, if published
- [ ] Fees — **with the exact academic year they apply to.** Never a bare number

## 5. Course structure
- [ ] Year-by-year or semester-by-semester structure for the main programmes
- [ ] Specialisations or electives available, and at which stage they are chosen
- [ ] Internships, industry projects, capstone requirements
- [ ] Credit system, if published

## 6. Admissions process
- [ ] The application steps in order
- [ ] Documents required
- [ ] Application dates — **with the academic year.** Flag any that have passed
- [ ] Campus visit policy

## 7. Conflicts and cautions (critical — this is what sells the demo)
- [ ] Any figure that appears differently on two official pages
- [ ] Any page that is visibly out of date (2023/2024 content still published)
- [ ] Anything a prospective student might ask that is simply not published
- [ ] Any claim that is marketing rather than verifiable fact

---

## Why this matters

Both previous agents won on candour: flagging that Designversity's site listed two
different M.Des fees, and that Apple Global School's age cutoff was from an expired
cycle. An agent for MIT ADT built on guessed facts would do the opposite — it would
state something the university knows is wrong, in front of the person evaluating it.

So: no facts in, no facts out.
